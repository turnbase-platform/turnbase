# Code of conduct

Be respectful. Discuss the work, not the person. Harassment, personal attacks, discrimination and
publishing other people's private information are not accepted in issues or any other project space.

The maintainer may edit, hide or delete comments and block users that break this. To report a problem
privately, use the contact on the maintainer's GitHub profile.

This is a short statement in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
which applies as the fuller reference.
