# Contributing to TurnBase

**Issues are welcome. Pull requests are not accepted for now.** TurnBase is a single-maintainer project and
its development flow merges directly to `master`; a pull request would sit unreviewed, which is worse for
you than saying so up front.

What helps:

- **Bug reports and questions** — open an issue in the repository concerned. Say what you did, what you
  expected, what happened, and the version or commit.
- **Ideas for the SDK** — open an issue in [`turnbase-sdk`](https://github.com/turnbase-platform/turnbase-sdk)
  describing the game you want to build and what the SDK blocks.
- **Security problems** — never in a public issue; see [SECURITY.md](SECURITY.md).

Where things are: the architecture, specifications and decisions are in the
[umbrella repository](https://github.com/turnbase-platform/turnbase); start at its README.
