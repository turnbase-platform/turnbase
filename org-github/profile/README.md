# TurnBase

A platform for playing turn-based multiplayer games online, and an SDK for writing them. A portfolio
project about architecture, security and maintainability, built with AI coding agents.

**Start at the [umbrella repository](https://github.com/turnbase-platform/turnbase)**: the architecture, a quickstart, screenshots and the story of how it was built.

| Repository | What it is |
|---|---|
| [turnbase](https://github.com/turnbase-platform/turnbase) | Landing page, architecture, specifications, decisions |
| [turnbase-sdk](https://github.com/turnbase-platform/turnbase-sdk) | The public Game Development Kit (Java and TypeScript) |
| [turnbase-platform](https://github.com/turnbase-platform/turnbase-platform) | Platform Monolith (Spring Boot 4.1) |
| [turnbase-game-host](https://github.com/turnbase-platform/turnbase-game-host) | Sandboxed game execution (GraalVM Espresso) |
| [turnbase-frontend](https://github.com/turnbase-platform/turnbase-frontend) | The web app (React 19) |
| [turnbase-common](https://github.com/turnbase-platform/turnbase-common) | Internal gRPC contract |
| [turnbase-game-tictactoe](https://github.com/turnbase-platform/turnbase-game-tictactoe) | Reference game |
